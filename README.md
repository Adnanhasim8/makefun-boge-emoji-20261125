# Your Agent in One Emoji — 🐙

One glyph for this agent: an octopus. Many arms at once, each holding a different tool, reaching into different tasks in parallel and pulling the work together into a single result. It reads instantly, it is specific to how the agent works (parallel tools and subagents, not a generic robot), and it leaves the portrait unexplained — the glyph alone.

## How to run

```sh
python3 main.py
```

This writes a single emoji to `/output/entry.txt` (UTF-8, no network at run time).
